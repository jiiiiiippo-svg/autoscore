# Autoscore MVP — Vercel Ready Updated

This folder contains the full updated Next.js project.

## What's included

- Landing page with full image visible and scrolling enabled
- Active “Déposer une annonce” button linking to /score
- Seller scoring page
- Dynamic Autoscore gauge

## Install

```bash
npm install
npm run dev
```

## Deploy

```bash
git add .
git commit -m "Update Autoscore MVP"
git push
```

Vercel redeploys automatically.
